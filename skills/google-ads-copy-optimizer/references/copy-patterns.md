# Copy patterns (shapes, not claims)

Every example below is a shape. Words in `{braces}` must be filled from the
fact sheet, the landing page or the search terms, with the source cited. If the
fact sheet has nothing to fill a slot, leave the slot out. Never fill a slot
with a plausible industry claim.

## Headline angles (up to 15 per RSA)

| Angle | Shape | Filled from |
|---|---|---|
| Core service + search language | `{top converting search phrase}` | search terms |
| Core service + place | `{service} in {city from service area}` | fact sheet, search terms |
| Page echo | `{landing page H1 or close variant}` | page language |
| What they carry or do | `{size or service list}` | fact sheet |
| Pricing model | `{pricing claim, e.g. flat rate, published price}` | fact sheet |
| Timing promise | `{delivery or response promise}` | fact sheet |
| Proof | `{rating} Stars, {count}+ Reviews` | fact sheet (GBP, with read date) |
| Use case | `{job type the page names}` | page language, search terms |
| Call to action | `{the page's own CTA wording}` | page language |

Rules: 30 characters; no two headlines saying the same thing; at least two carry
the top converting search language; at least one carries a fact only this
business can claim; pin only the core service line when needed.

## Description slots (up to 4, 90 characters)

1. Value plus the page's call to action.
2. Proof and differentiators from the fact sheet.
3. How it works, in the page's own steps.
4. A use case or segment the search terms show converting.

Each stands alone; at least one names the service area; at least one carries a CTA.

## Assets

- Sitelinks (25 / 35 / 35): one per real page that exists and returns 200;
  title in the page's own words.
- Callouts (25): fact sheet lines only.
- Structured snippets: values from the fact sheet's services or sizes list,
  never a list the fact sheet does not contain.

## QS component to copy fix

| Below Average | What copy can do | What it cannot |
|---|---|---|
| Expected CTR | Lead with converting search language and a unique fact from the fact sheet | Fix a weak offer |
| Ad Relevance | Echo the keyword and search phrasing in two or three headlines; split an ad group that serves several intents (that is a restructure, hand to change-scripts) | Rescue a keyword in the wrong ad group |
| Landing Page Experience | Use the page's own words so ad and page agree; drop promises the page does not back | Fix the page; note it under Page notes |
