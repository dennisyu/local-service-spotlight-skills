Have cheaper models write the 20-page report

Our first 20-page audits cost about $281 each in AI fees, because our most expensive model did every step. Now a cheaper model writes the pages, code draws and checks them, and the expensive model only reviews the finished file. From research that is already done, the writing costs a few dollars or less. That is cheap enough to run an audit every month, not once a year.

What changed

  • Models write words; code draws the pages. Every model fills the same 20-page template, so a cheaper model never has to invent the design.
  • 44 automatic checks run on every draft. They look for evidence on every page, scores that add up, a picture on every page and nothing from the do-not-print list. Each failure tells the writer exactly what to fix.
  • The expensive model reviews once, with fresh eyes. It sees only the finished files, never the drafting. A serious finding goes back for a fix before the audit can pass.
  • Every action names who does it. Anything that touches a client's website, profiles or listings waits for a named person's yes.

What we tested

We gave Claude Sonnet the research behind one of our October company audits, with our own conclusions taken out, and let it build all 20 pages with the kit. A separate reviewer that built none of the audits scored every page against the original audit's 14 insights. Sonnet found 11, partly found 1 and missed 2, for $2.45 in measured model fees. Our first try at this test was not fully blind: some of our guidance was still inside the research file. We removed it and ran the test again. The 11 of 14 is from the clean run.

Run it yourself

The kit is free on GitHub: our 20-page audit kit (Audit Factory 20). It builds a made-up demo business with no keys at all. For a live run, one OpenRouter key reaches every model the kit uses, Claude included. Create a key at openrouter.ai and keep it in your own secret store, never in a file.

cd audit-factory
pip install -r requirements.txt && python -m playwright install chromium
python -m factory20 init runs/demo --from-demo
python -m factory20 run runs/demo --tier openrouter-lean --max-usd 3

Every call asks for providers that keep no prompts. Every run has a spending cap. The cost of each call goes into a receipt file next to the PDF.

What is not proven yet

  • No live OpenRouter bill yet. The one-key tiers are tested against a stand-in for OpenRouter's API, not the real one. The first live run is next, and its bill replaces the estimates above.
  • Research for a new subject is not cheap yet. Until the code that collects sources is built, the agent running the audit does the research in its own session.
  • The cheapest tier is experimental. It uses no Claude model unless a cheaper one fails twice, and nobody has measured its quality.
