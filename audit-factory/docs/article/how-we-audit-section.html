Have cheaper models write the 20-page report

One of our first 20-page audits cost $281 in AI fees. Our most expensive model did every step. Now a cheaper model writes the pages. Code draws and checks them. The expensive model only reviews the finished text. We rebuilt two of our audits this way from their research. Each cost $1 to $7 in AI fees. Blind judges graded our standard version about as well as the originals. That is cheap enough to run an audit every month, not once a year.

What changed

  • Models write words; code draws the pages. Every model fills the same 20-page template, so a cheaper model never has to invent the design.
  • 47 automatic checks run on every draft. They look for evidence on every page, scores that add up, a picture on every page, nothing from the do-not-print list, and the name and face of the person who prepared the audit. Each failure tells the writer exactly what to fix.
  • The expensive model reviews once, with fresh eyes. It sees only the finished files, never the drafting. A serious finding goes back for a fix before the audit can pass.
  • Every action names who does it. Anything that touches a client's website, profiles or listings waits for a named person's yes.

What we tested

We gave Claude Sonnet the research behind one of our October company audits, with our own conclusions taken out, and let it build all 20 pages with the kit. A separate reviewer that built none of the audits scored every page against the original audit's 14 insights. Sonnet found 11, partly found 1 and missed 2, for $2.45 in measured model fees. Our first try at this test was not fully blind: some of our guidance was still inside the research file. We removed it and ran the test again. The 11 of 14 is from the clean run.

Before spending anything on the one-key path, we tested it against a stand-in for OpenRouter's API, and a separate agent reviewed the code. Together they found seven problems, all fixed. The biggest: Claude's Sonnet and Opus models think before they answer, that thinking is billed, and our first estimate left it out. Counting it raised the estimates to the numbers above.

Then we rebuilt two finished audits, a company audit and a person audit, from their research with the original conclusions taken out. Two judges that saw none of the work graded each rebuild blind, side by side with its original. The standard tier passed on both: the company audit at once, and the person audit after we fixed two problems the first rebuild showed. In the last rebuild both judges gave it an A-, the same as its original. The cheaper lean tier passed the company audit and failed the person audit, on one serious error that its single review found but had no round to fix. Our best model's findings recovered more of the originals' insights, 12 and 17 of 20 against lean's 7 and 9, so person audits stay on the standard tier.

Run it yourself

The kit is free on GitHub: our 20-page audit kit (Audit Factory 20). It builds a made-up demo business with no keys at all. For a live run, one OpenRouter key reaches every model the kit uses, Claude included. Create a key at openrouter.ai and keep it in your own secret store, never in a file.

cd audit-factory
pip install -r requirements.txt && python -m playwright install chromium
python -m factory20 init runs/demo --from-demo
python -m factory20 run runs/demo --tier openrouter-lean --max-usd 3

Every call asks only for providers that do not collect user data. A confidential audit also asks for zero data retention; for the strictest version, set your OpenRouter account's privacy setting to "ZDR only". Every run has a spending cap it never crosses, and the cost of each call goes into a receipt file next to the PDF.

What is not proven yet

  • No live OpenRouter bill yet. The one-key tiers are tested against a stand-in for OpenRouter's API, not the real one. The first live run is next, and its bill will check the costs above.
  • The lean tier's own drafting model is not tested yet. In the pilot, Claude models stood in for its DeepSeek and GPT models.
  • No home-service audit has been rebuilt yet. It is the pilot's third subject.
  • Research for a new subject is not cheap yet. Until the code that collects sources is built, the agent running the audit does the research in its own session.
  • The review reads the text, not the pages. The expensive model checks the finished text, the evidence and the results of the checks. It does not see the page images yet, so a person still looks at the photos and the layout.
  • The cheapest tier is experimental. It uses no Claude model unless a cheaper one fails twice, and nobody has measured its quality.
